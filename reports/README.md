# Local Verification & Quality Gate Reports

This directory contains persistent, reproducible verification reports and evidence summaries generated by the local verification runner (`scripts/verify-release.sh`).

## Directory Hierarchy

- `latest/`: Always points to the most recent comprehensive verification run across static analysis, unit tests, PostgreSQL multi-engine tests, security audits, and real Laravel application scenarios.
  - `SUMMARY.md`: Executive summary and key verification metrics.
  - `STATUS.md`: Release readiness dashboard.
  - `SECURITY.md`: Dependency security disclosure, advisory analysis, and production safety perimeter.
  - `COMPATIBILITY.md`: Supported runtime matrix (PHP 8.2-8.4, Laravel 11-12, SQLite, MySQL, MariaDB, PostgreSQL).
  - `TEST_RESULTS.md`: Exact unit and integration test outputs with execution times and assertions.
  - `INTEGRATION.md`: Real Laravel application lifecycle test results (.workbench/lifecycle-test-app).
  - `PRODUCTION_SAFETY.md`: Adversarial safety tests, environment fail-closed verification, and bypass rejection.
  - `KNOWN_LIMITATIONS.md`: Explicit technical boundaries and non-goals.
  - `manifest.json`: Machine-readable metadata, git commit SHA, and test run fingerprints.
- `runs/`: Archived execution logs organized by timestamp / unique run ID.
